# 簿記タイクーン

日商簿記1級のゲーミフィケーション学習アプリです。問題に正解すると「売上」が積み上がり、個人商店 → 株式会社 → 上場 → 連結グループ → 簿記の神へと会社が成長していきます。

**▶ アプリを開く: https://piro2020.github.io/boki1-tycoon/**

ブラウザだけで動く単一HTMLファイルです。インストール・ログイン・サーバー通信は不要で、学習履歴は端末内（localStorage）だけに保存されます。

## 遊び方

- **売上**: 正解すると売上が入ります。基本額（○×100・理論200・仕訳300・計算400・過去問1,000）× 難易度（★1〜★3）× コンボ倍率（最大×2）× 初回正解1.5倍。5%の確率で「大口受注」が発生し×3。
- **会社の成長**: 累計売上に応じて 個人商店 → 合同会社 → 株式会社 → 支店開設 → 上場準備 → グロース → スタンダード → プライム → 持株会社 → 連結グループ → グローバル → 簿記の神 の12段階。★3以上の事業部は本社の横に子会社ビルとして建ちます。
- **本日の業務**: 毎日3件の課題が出ます。復習期限が来た理論カードがあれば優先的に含まれます。3件完了で「決算を締める」とボーナス。
- **連続営業日**: 1日1セッション完了で1日カウント。休んだ日は有給休暇券（最大2枚）が自動消費され、連続記録を守ります。
- **事業部★**: トピックごとに通算正解数と正答率で★0〜5。直近10問の正答率が60%未満のトピックは「弱点」として赤枠表示され、弱点特訓の対象になります（売上×1.5）。
- **模擬決算**: 10問ミックス＋過去問1問を10分で解く本番形式。70%以上で合格ボーナス。1日1回。
- **理論カード**: 0・1・3・7・14・30日の間隔反復。誤答すると翌日に再出題されます。

## iPhoneで使う（推奨）

1. Safariで上記URLを開く
2. 共有メニュー → **ホーム画面に追加**
3. 以降はホーム画面のアイコンから起動

ホーム画面版は独自のストレージ領域を持つため、Safariの「7日間未使用でサイトデータ削除」の影響を受けにくく、学習履歴が消えにくくなります。

## データの保存と移行

- 履歴は端末内の localStorage に保存され、外部には送信されません。
- 別の端末に移すときは 設定 → **書き出し** でJSONを保存し、移行先で **取り込み** します。
- ブラウザのサイトデータを消去すると履歴も消えます。定期的な書き出しをおすすめします。

## 注意事項

- 問題・解答・解説はAIが生成し、別のAIが独立に検算したものです。公式の模範解答ではありません。誤りを見つけた場合は Issue で教えてください。
- 「ボス問題」は日商簿記1級の過去問を題材に再構成したもので、解答は公式解答ではなく独自に算出したものです。
- 個人の学習用に作成したものです。検索エンジンには登録していません（noindex）。

## 技術メモ

- 依存ライブラリなしの単一HTML（HTML/CSS/JavaScript）。問題データもファイル内に埋め込み。
- このリポジトリには配信用のビルド成果物（`index.html`、`apple-touch-icon.png`）のみを置いています。
- ソース（`src/`、`content/`、`build.py`）は別管理です。
